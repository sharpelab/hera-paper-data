# Device Y — geometry and build timeline (supplied)

Dual-gated trilayer-graphene Hall bar. Coordinate frame: flake-image µm,
origin at the image's lower-left corner (both contracts use this frame).

## Transport channels (four-terminal Rxx regions between voltage-probe pairs)

| Channel | Probe pair | Region probed (x, y µm) |
|---|---|---|
| ch_A | C1–C2 | x 3–13, y 10–20 |
| ch_B | C3–C4 | x 17–27, y 10–20 |
| ch_C | C5–C6 | x 31–41, y 10–20 |
| ch_D | C7–C8 | x 44–54, y 10–20 |

## Build timeline

1. Exfoliation; flake selected (2025-11-02)
2. **Raman map acquired (2025-11-10)** — stage S1: bare flake on SiO₂/Si,
   pre-pickup. Map window x 0–42, y 0–30 µm (the x > 42 µm end of the
   flake was outside the mapped window).
3. hBN pickup + full encapsulation (2025-11-20; pickup direction not
   recorded)
4. **Contact metallization** (2025-12-01) — Cr/Au evaporated; leads for
   C3/C4 run directly across the ch_B region
5. Top-gate deposition (2025-12-08)
6. Cooldown + transport campaign (2026-01, run ids in the transport
   contract)

Registration: the Raman map frame was registered to the device image via
two flake-corner fiducials; estimated registration uncertainty **±1.5 µm**
in both axes.
