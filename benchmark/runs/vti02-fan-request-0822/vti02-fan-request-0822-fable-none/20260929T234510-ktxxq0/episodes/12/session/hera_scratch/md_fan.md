## HERA — Step 5: Landau fan at D = 0 (`landau-fan`) — the stacking-call dataset

**Plan step 5** (`hera_scratch/plan.md`, recreated post-handoff). Runs 6/7 (ana cells 14–17) pass the feasibility gate: SdH from ≤ 0.7 T on both carrier signs, but the spot FFTs cannot separate harmonics from genuine subband tones (electron side: 7.1 T + 2×/3×/4× content vs a real heavy pocket near 26 T; hole side: multi-band with 12.3 T ≈ F_full). The fan resolves this by slope: harmonics scale with their parent tone vs n, subbands carry their own frequency-vs-n line; and the filling-factor / LL-crossing structure fanning from the CNP gives the zero-LL degeneracy — together the ABAB / ABCA / ABCB discriminators.

**Geometry:** fast axis = n from −1.25 to +3.20×10¹² (201 pts, Δn ≈ 2.2×10¹⁰), TG+BG co-swept along the run-5 calibrated D = 0 line (`multimegasweep`, ratio 0.773, n_offset −0.089×10¹², D_offset −0.013 V/nm); slow axis = B from 0 → 10 T in 0.1 T (101 rows, ascending from where the magnet sits, ending at the top — the next step rides it down). **Coverage:** the full validator-realizable D = 0 window minus a ~2% margin at both ends (n = ±1.27/+3.27 map to the exact TG rails); nothing physical is excluded.

**Pacing (measured, run 5):** fast_delay 1.0 s + 0.10 s/pt reads (4873 s / 63 rows / 66 pts) → 221 s/row + flyback ~4.5 s + 0.1 T ramp 44 s + 3 s settle + slow_delay 1 s ≈ 273 s/row × 101 ≈ 7.7 h; with this session's actuals running 5–10% over: **≈ 8–8.5 h**. Sensitivity 200 µV = 20 kΩ FS (run-4 lesson: size to the gapped-CNP expectation, not the B = 0 peaks); the ν = 0 ridge may still rail at high B — accepted, the rail is gap evidence.

**Checkpoints** (reading the armed `hera-watch --follow` digests): (1) first 2–3 rows — leakage, rail, dead channel, T stable; (2) row ~20 (B ≈ 2 T) — re-form the partial fan, Landau lines must resolve in n, else interrupt and re-grid; (3) row ~50 (B ≈ 5 T) — interim fan + FFT-vs-n read, continue/adjust call. Abort lever: `nb-collab interrupt` (leak trip is automatic at 1 nA; magnet keeps ramping to the row setpoint on interrupt — re-read field after any abort).
