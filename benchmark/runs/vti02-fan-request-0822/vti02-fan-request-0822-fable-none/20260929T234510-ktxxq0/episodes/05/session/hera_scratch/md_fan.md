## HERA — Step 4: Landau fan at D = 0 (`landau-fan`) — the stacking-call measurement

Plan step 4 (operator-requested). The spot checks fix the design: e-side (run 6, data/6) shows a light F = 7.1 T pocket carrying only ~21 % of n with the rest LK-dead-heavy; h-side (run 7, data/7) is multi-tone (4.7/6.6/8.5/12.3 T). The stacking call needs **F(n)** on both signs — branch count, slopes, and density partition vs the full-density Luttinger line separate ABAB (light+heavy pair, partial slopes) from ABCA (single full-slope branch) from ABCB (light-cone + heavy remainder). **Grid:** fast axis = (V_tg, V_bg) co-swept along the calibrated D = 0 line (run-5 cal, `cal_run5.json`), n = −1.25 → +3.25×10¹² in 121 pts; slow axis = B, 1.2 → 10 T in 97 rows **uniform in 1/B** (Δ(1/B) = 7.6×10⁻³ → F_Nyquist 65 T, ΔF ≈ 1.4 T — resolves every observed tone and the 33 T ABCA discriminator). Magnet sits at 0 T → fan ascends, ends at 10 T (never re-traverse). **Coverage trade:** hole side reaches only n = −1.25×10¹² (TG −0.3 V limit on the D = 0 line) — the h-side branch read is confined to the near-CNP multi-pocket regime; B < 1.2 T is not in the fan (covered 1D by runs 6/7); full h-side coverage would need a different D or a limit change — banned. Sensitivity 100 µV (10 kΩ FS, 17× run-7's high-B max per the run-4 sizing lesson); the ν = 0/CNP stripe at high B may rail — accepted and excluded from FFT (a railed stripe is itself a gap marker). **Price** (run-5 timing cal, 1.17 s/pt at fast_delay 1.0 s): 97 × 150 s rows + 64 min total ramp = 5.1 h → **headline ≈ 5 h 45 m** (actuals run over estimates on this rig). **Checkpoints:** first rows (~10 min: rail/leak/sensitivity/co-sweep sanity), then interim FFT reads at ~2.5 T (row ~55), ~4 T (row ~75), ~6.5 T (row ~88) — continue/abort with the fan readable from partial data at every stage since low-B rows land first.
