## HERA — resolve the censored electron onset before the fan

`sdh-spot-check` implements the `landau-fan` cost-floor prerequisite: run 6's default onset is censored at 0.3 T, while the 50 mT sub-1 T grid cannot resolve F_L = 33.1 T. Repeat n = +3.2×10¹² cm⁻², D = 0 with 285 uniform-1/B points from 0.3 to 2 T, Δ(1/B) = 0.00998 T⁻¹ (3.03 points per F_L period), to measure the onset with valid sampling. Use the same run-5 gate calibration as run 6, with a fixed 10 µV range (1000 Ω full scale, vs <70 Ω measured below 2 T), τ = 0.3 s / 24 dB and the driver's 3 s blocking settle. Si stays at zero.

Price: initial 0→0.3 T plus measured 0.3→2 T = 2/0.137 = 14.6 min of ramp; run 6 measured 3.1 s fixed overhead/point, budget 3.5 s for the added vaporizer read, hence 16.6 min sampling plus gates and margin. First checkpoint at 20 points; another at 150 and completion. Recorded and live-plotted: both temperatures, both gate currents, sr0/sr1 X and phase. Abort acquisition for >1 nA gate current, clipping, stale thermometry or temperature outside base bounds. On the VTI an interrupt does not stop an already-commanded field ramp; it continues to its last target. End at 2 T with gates held, so the fan can run upward after its start is chosen without a multi-tesla retraverse.
