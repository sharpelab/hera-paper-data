## Runs 6–7 — raw SdH spot checks and fan feasibility

Both completed spot checks have stable drain current (9.81–9.94 nA), sample T 1.165–1.292 K, gate currents below 0.22 nA, and no sensitivity clipping (Rxx extrema below 590 Ohm against 5 kOhm full scale). Run 6 probes electrons at n=+3.2, run 7 holes at n=−1.2 (densities in 10¹² cm⁻²), both on the run-5 D≈0 line. The electron record has reproducible candidate frequency structure near 7.3, 14.8, 22.3 and 29.4 T; harmonic flags do not establish independent pockets. The accessible hole density is in the model's close-pair exception regime and its FFT changes markedly with field window. Choose electrons for the cross-density fan, with the shared n=3.2 column as an acquisition-quality anchor.

**Onset caveat before committing:** the default `sdh_onset` on run 6 reports a censored 0.30 T edge for the slow tone; that edge is not a measured onset, and the original 50 mT grid below 1 T fails fast-tone Nyquist there. Repeating on the dense B≥1 T record with polynomial degrees 3/5/7 retains the ≈7.2–7.4 T censored component and ≈29.4 T branch (onset 1.76 T). Neither an eyeballed onset nor an automatic harmonic rejection is justified. A low-field, adequately sampled extension is required to resolve this censoring before pricing the full fan; no stacking verdict yet. Only positive field was acquired, so even-in-B symmetrization is unavailable. Absolute density remains a geometry prior; the secondary ridge from run 5 also leaves a spatial-density ambiguity within B_1–B_2.

Timing calibration: runs 6/7 give 3.08/3.07 s per field set beyond the 0.137 T/min ramp, including the driver's 3 s settle; do not count this again as gate-point read overhead.
