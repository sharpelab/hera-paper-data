## Runs 6 / 7 — SdH spot checks at D = 0 (`sdh-spot-check`): electron n = +3.2×10¹² (0 → 10 T), hole n = −1.2×10¹² (10 → 0.3 T)

Raw Rxx(B) first, then the 1/B FFT (5th-order B-space background, log R, two windows). No leakage (gate currents ≤ 0.22 nA offsets), T 1.17–1.29 K.

**Read.** Electron side (run 6): Rxx reaches ≈ 0 between features from ~2 T — quantum-Hall regime well inside the field range. FFT (1.5–10 T, ΔF 1.8 T): **7.1, 15.9, 22.9, 30.0 T** (`sdh_onset`'s matched-filter tracks put the upper three at 14.1 / 22.2 / 29.5 T). These close as **F1 = 7.1, F2 = 22.9, F2 − F1 = 15.8, F1 + F2 = 30.0** — the tone set of *two* Fermi surfaces plus their mixing products, with density shares 0.24 / 0.76 (Bernal-tetralayer λ ratio predicts ≈ 0.28 / 0.72). A single band cannot produce that set (its harmonics would be 30, 60 T). The competing reading — a single 7.1 T family with harmonics 14.2 / 21.3 / 28.4 T (`sdh_onset` flags them that way) — is **not excluded**: the offsets (≈ 1–1.6 T) are inside ΔF = 1.8 T. One density can't split them; the n-dependence does (harmonics scale as k·F1(n), mixing tones as F2 ± F1). ΣF = 30.0 T vs F_L = 33.1 T from the geometry-prior c_tg → the absolute density scale is probably ~0.91× the prior (to be fixed independently from the fan's ν-line slopes). Hole side (run 7): 5.3 T dominant plus 10.6 / ~13–14 T, onset ≈ 0.7 T — messier near the CNP (band-overlap / trigonal-warping regime), not interpretable from one density.

**Take:** suggestive of **two bands (ABAB-like)** on the electron side, not yet evidence — the harmonic reading survives; a single density can't separate mixing tones from harmonics or rule out a series second region (run 5 ridge B, +0.43×10¹²). → the D = 0 Landau fan (plan step 4) — F_i(n) for each tone, and ν-slopes for the absolute density scale. Field window from these runs: oscillations from ≤ 1 T (light tone persists to 0.3 T; heavy tones onset 1.3–1.9 T).
