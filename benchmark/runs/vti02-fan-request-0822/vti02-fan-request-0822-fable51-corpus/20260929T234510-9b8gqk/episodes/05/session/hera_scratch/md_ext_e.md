## HERA — Step 3c: low-field onset pin at n = +3.2×10¹² (`sdh-spot-check` extension of run 6), B 0.3 → 1.3 T — precedes the fan

**Spot-check read (runs 6, 7; full analysis in ana).** Electron side (run 6, n = +3.2, F_L = 33.1 T): clean SdH, dominant tone 7.3 T (`sdh_onset`, SNR 96) with a harmonic comb 14.8 / 22.3 / 29.4 T that grows above ~4 T where the trace turns QH-like (deep minima at 4.3 / 6.0 / 7.1 T, R → 530 Ω at 8.8 T). The 7.3 T tone matches the model's ABAB light tone at this density (7.3 T; heavy 25.8 T; ABCA 33.1 T) but the 29.4 T "4×" line is also within one δF (2.1 T) of the heavy/F_L candidates — undecidable at one density, exactly what the fan's F(n) resolves. Hole side (run 7, n = −1.2, F_L = 12.4 T): onset 0.71 T but the near-CNP exception regime (tones bunched 4.7 / 6.6 / 9.4 / 12.3 T, R climbing to 590 Ω at 10 T) and the D = 0 line only reaches −1.27×10¹² — no room for the |n| ≳ 2–3 design densities. **The fan goes on the electron side.**

**Why this cell first.** The 7.3 T tone is *censored* at the 1.0 T edge of run 6's 10 mT segment (the 50 mT leg below 1 T under-samples a 7 T tone below ~0.85 T) — so the onset that sets the fan's B_lo is unmeasured. `landau-fan` step 1 lever (1): pin it with a cheap low-field extension rather than pay ~1–2 h of blind sub-onset rows. Same column as run 6 (shared-density quality comparison), uniform 1/B (Δ(1/B) = 0.020, Nyquist 25 T), sr1 20 µV (R ≤ 60 Ω here). Preconditions: base T, B ≈ 0 (handoff), Si 0, heaters off. Ends at 1.3 T with the gates at the spot; the fan's first slow set ramps down to B_lo from there.

**Fan design (landing after this lands):** `landau-fan-vti`, D = 0, n = 1.5 → 3.2×10¹² (51 pts, Δn = 0.034 → 2.8 rays/Δn at 1 T), B_lo = max(onset, 0.6 T) → 10 T uniform 1/B, Δ(1/B) = 0.010 (Nyquist 50 T = 1.5× F_L(3.2)), sr1 100 µV (10 kΩ FS; low-n × high-B corner ≈ 1–3 kΩ; measured LSB 0.19 Ω at 50 µV → 0.37 Ω, SdH 20–50 Ω ≥ 50 LSB), fast_delay 1.2 s (4τ), slow_delay 3 s. Priced 3.2 h (B_lo = 1.0, 91 rows) to 4.5 h (B_lo = 0.6, 160 rows); B_hi = 10 T rather than 7 T buys the ν = 12 ladder for n ≤ 2.9 (adjacent-N check) for +35 min.
