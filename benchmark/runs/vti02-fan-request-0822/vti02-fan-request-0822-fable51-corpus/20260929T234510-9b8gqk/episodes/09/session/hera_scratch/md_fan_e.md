## HERA — Step 4: Landau fan, electron side (`landau-fan-vti`), D = 0, n = +3.2 → +1.0×10¹², B 0.5 → 10 T uniform-1/B

**Why this fan (spot checks, ana cells 14–15):** run 6 (n = +3.2×10¹², F_L = 33.1 T) carries a 7.47 T fundamental with an exact 2×/3×/4× comb (14.9 / 22.4 / 29.9 T) and nothing resolved at F_L. Two readings survive at one density and cannot be split there: a single 7.5 T pocket + harmonics, or the ABAB template at global scale 0.90 — light 7.47 + heavy 22.41 = 29.88 T (partition 0.25 / 0.75; model at +3.2: 7.3 / 25.8 T) with the 29.9 T sum tone the symmetry-allowed inter-block breakdown. **Only the n-dependence separates them**: a harmonic tracks 3·f_light(n) exactly (model 3×3.55 = 10.7 T at n = 2), an ABAB heavy pocket follows its own Onsager curve (17.1 T at n = 2) and runs to F_L as the light pocket empties (n ≈ 0.8–1.0: model 0.6 / 9.8 T); ABCA would be one tone at F_L(n) everywhere. The hole side reaches only |n| ≤ 1.27×10¹² (the investigation's low-|n| exception regime; run 7 shows a strong tone *at* F_L = 12.4 T plus ~6.5 T — consistent with a close ABAB hole pair + sum tone, not decisive), so the fan goes on the electron side. Region B (mosaic, +0.43×10¹² relative to A) adds tones at ×1.13–1.4 in n — read per column, checked against the same F_L.

**Design (Step 2 numbers, computed):** fast axis 56 paired (V_tg, V_bg) points along D = 0 from n = 3.2 → 1.0 (δn = 0.04×10¹²; ≥ 2 points per LL ray for a full-density pocket down to 0.83 T and for a 0.25·n pocket down to 0.2 T — the ≥ 22 T content onsets at ≥ 1.36 T in run 6, so the n-Nyquist floor for it is met with margin). Slow axis uniform in 1/B in **two segments**: 0.5 → 1.4 T at Δ(1/B) = 0.020 T⁻¹ (65 rows; Nyquist 25 T — below 1.4 T only the ≤ 7.5 T light tone is above onset), then 1.4 → 10 T at Δ(1/B) = 0.00975 T⁻¹ (63 more rows; Nyquist 51 T = ⅓-Nyquist on F_L(3.2) = 33 T; run 6's only content above 34 T is 45/60 T harmonics at 5–7 %, which fold to 41–56 T, outside the claim band). **128 rows × 56 = 7168 points.** Resolution: δF = 1/(1/0.5 − 1/10) = 0.53 T for the light tone, 1/(1/1.4 − 0.1) = 1.63 T for the ≥ 22 T tones — the 22.4-vs-25.8 T (3×light vs ABAB heavy) split at n = 3.2 is 2.1·δF, and the split grows to > 6 T by n = 2. B_lo = 0.5 T is set by the light tone at the low-n edge (model 2 T at n = 1.5 → 3.8 periods; `sdh_onset` on run 6 reports the light tone censored at the record edge, i.e. onset < 1 T, with the 0–1 T leg under-sampled at 50 mT). Sensitivity fixed at **100 µV = 10 kΩ FS**: the worst corner (n = 1.0 × 10 T; R(B = 0) = 117 Ω from run 5, QH-regime Rxx maxima 0.5–0.6 kΩ at |n| = 1.2–3.2 in runs 6/7) is expected ≈ 1 kΩ → ≥ 5× headroom, at the price of 2× coarser resolution at the ~10 Ω high-n low-B corner (run 6 had SNR 40–90 there at 5 kΩ FS). Dwell: fast_delay 1.0 s (run 5 calibration 1.17 s/pt all-in; τ = 0.3 s / 24 dB → group delay ≈ 1 column = 0.04×10¹² uniform n-lag, same for every row, so F(n) columns are self-consistent), slow_delay 3 s over the flyback transient; each B step blocks through the ramp + 3 s driver settle.

**Price:** grid 7168 × 1.17 s = 2.3 h + bare traverse 9.5 T / 0.137 T/min = 69 min + 128 rows × ~7 s (settle + slow_delay + flyback) = 15 min → 3.7 h nominal, **≈ 4 h realistic**, ending at **10 T** with the gates at the n = 3.2 point (next step — the LK mass split or the ride-down — starts there; no re-traverse). **Checkpoints:** first rows (~10 min: signal levels vs run 6 at n = 3.2, rail counter, leakage, B readback tracking setpoints) → abort if railed/flat; at ~1.4 T (end of the low segment, ~1.5 h): per-column FFT of the landed rows — does the light tone's F scale with n? — continue/adjust; at ~4 T (~2.7 h): heavy-tone F(n) on the landed 1.4–4 T record (δF ≈ 2.2 T) vs 3×f_light(n). Cheap kills only in the first two; the last is an interim read.
