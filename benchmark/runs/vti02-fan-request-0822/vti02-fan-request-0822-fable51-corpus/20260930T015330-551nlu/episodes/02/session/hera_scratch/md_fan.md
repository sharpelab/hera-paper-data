## HERA — Step 4: Landau fan, electron side (`landau-fan-vti`), D = 0, n = +1.0 → +3.2×10¹², B 0.8 → 10 T

**Why this fan, from the spot checks (runs 6/7, read with `sdh_onset` / `sdh_fft`; the ana cells follow).** Electron side, n = +3.2 (F_L = 33.1 T): a dominant fast tone at ≈ 29.5–30 T (onset 1.75 T, SNR ≈ 90) plus a slow ≈ 7.2 T tone (onset 1.35 T) with a harmonic comb 14.1 / 22 / 29.5 / 58.7 T, and a weaker 9.5 T tone (onset 0.88 T). Model (`fs_count_b0`) at +3.2: ABAB pair 7.3 / 25.8 T, ABCA singleton 33.1 T. The single-density read is **underdetermined**: {7.2, 29.5} is an ABAB-like pair summing to 36.7 T (lever-arm scale 1.11) *or* a 29.5 T singleton (scale 0.89) with 7.2 T as a ¼-superstructure — both inside the ±10–15 % scale prior, and the ABAB light/heavy ratio passes through exactly 4 near n ≈ 2.5. Only F(n) across density separates them: under ABAB the heavy tone runs 0.78 → 0.95 F_L from n = 3.2 → 1.0 (curved), under ABCA F ∝ n (straight through the CNP); the ≈ 7 T tone either follows its own Onsager curve (3.6 → 7.3 T over n = 2 → 3.2) or stays locked at F_heavy/4. Hole side (run 7, n = −1.2, onset 0.71 T) is the cleaner trace but the D = 0 line reaches only n ≈ −1.13 inside the validators — the low-|n| exception regime (close balanced ABAB pair vs a heavy-mass ABCA singleton), so a hole fan cannot carry the call. **Coverage trade:** hole side excluded from the fan; n > 3.2 is a validator edge (V_tg = 1.0 V at n = 3.25); the top column reproduces run 6 on a different grid (grid-change reproduction for free).

**Design (landau-fan step 1, computed).** B_lo = 0.8 T — the measured onsets are 0.88 T (electron, full record, near-residual tones excluded) and 0.71 T (hole); 0.8 gives 10 % margin for onset drift with n. Uniform-1/B slow axis, Δ(1/B) = 0.008 /T (Nyquist 62.5 T — covers the 58.7 T harmonic so it cannot fold onto F_L; F_L/3 needs 0.0101) → **145 rows**, dB 5 mT at 0.8 T, 0.8 T at the top. Fast axis 81 paired-gate points, dn = 0.0275×10¹² (ray Nyquist at 0.8 T is 0.077 → 2.8 pts/period, 3.5 at 1 T). Record above onset: δF = 1/(1/0.8 − 0.1) = 0.87 T — separates the ABAB-heavy (25.8) from the ABCA singleton (33.1) by 8 δF; the ABAB partner has ≥ 5 periods for n ≥ 2.2 (3–4 periods down to n ≈ 1.6; below that it is unresolvable in any 10 T window — a stated limit, not a defect). Sensitivity fixed at 100 µV (10 kΩ FS): the worst corner is n = 1.0 × 10 T (ν ≈ 4, QH regime) — R(0 T) ≈ 120 Ω there (run 5) and the QH-regime MR is unbounded; 50 µV would rail it. Dwell: τ = 0.3 s / 24 dB (read, not assumed); fast_delay = 1.5 s = 5τ (78 % settled per step) — a knowing bend of the recipe's ~6τ: the fast axis is n, the per-column extraction is along B, and the residual step memory at dn = 0.0275 costs ≤ 23 % of the heavy-tone amplitude at 1 T (0.28 cycles/column), 6 % at 2 T, 0 frequency distortion; the light tone shifts 0.085 cycles/column — untouched.
