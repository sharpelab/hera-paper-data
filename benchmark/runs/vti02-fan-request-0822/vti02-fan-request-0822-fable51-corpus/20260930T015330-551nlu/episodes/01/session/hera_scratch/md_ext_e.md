## HERA — Step 3c: low-field onset extension, electron side (`sdh-spot-check`), n = +3.2×10¹² at D = 0, B 0.25 → 1.2 T

**Why this before the fan.** The spot-check read (ana, runs 6/7) puts the fan on the electron side: run 6 carries a strong tone set {7.1, 22.1, 29.5} T (+14.1 T) at n = +3.2×10¹² — 7.1 + 22.1 = 29.2 ≈ the 29.5 T tone, i.e. the {f₁, f₂, ≈F_L} set the investigation flags as underdetermined (ABAB pair + symmetry-allowed breakdown sum-tone, or a singleton at F_L with scale 0.89) — while run 7 (hole, n = −1.2×10¹²) sits in the model's low-|n| close-pair regime (5.3/7.0/12.3 T, messy). The fan's job is the F(n) trajectory + Luttinger sum across n. `landau-fan` step 1 lever (1): B_lo = the *measured* onset — and `sdh_onset` on run 6 returns the carrying 7.1 T tone **censored at the record edge (0.30 T)**, with run 6's sub-1 T leg at 50 mT, which under-samples a 7 T tone below ~0.85 T (aliased, not a measurement). The recipe's branch for a censored carrying tone is a cheap low-field extension before committing the long fan; B_lo is the ±3 h lever here (uniform-1/B rows ∝ 1/B_lo: 0.7 T vs 1.0 T is ~150 vs ~105 rows), and the model partner tone at n = 2×10¹² (3.5 T) needs a 1/B span ≥ 1.4 T⁻¹ (B_lo ≈ 0.65 T) for ≥ 5 periods.

**Design.** Same gate point as run 6 (n = +3.2, D = 0 → V_tg = +0.984, V_bg = +1.166 V). Field uniform in 1/B (`field_invB`, 96 pts, 0.25 → 1.2 T ascending — the magnet sits at 0 T): Δ(1/B) = 0.033 T⁻¹ = 3 pts/period on a 10 T tone, 4.2 on 7.1 T (the 22–30 T tones are dead below their 1.4–1.9 T onsets, so nothing to alias); overlaps run 6's 10 mT leg over 1.0–1.2 T for a cross-check. Uniform-1/B rather than the recipe's uniform-B branch because on this rig the per-point overhead (~8 s) dominates a 1 T traverse (7 min) — 96 points instead of ~230 for the same Nyquist. `delay = 0`: each blocking set + 3 s driver settle = 10 τ (τ = 0.3 s, 24 dB/oct). sr1 at **20 µV (2 kΩ FS)**: run 6 read ≤ 57 Ω below 1.04 T → 3 % of FS, 35× headroom, 2.5× finer digitisation than run 6's 50 µV for the low-B oscillation amplitude. Leak trip 1 nA on both Keithleys (TG at +0.98 V ran at ~0 pA baseline in run 6).

**Price.** From run 6 (14.6 s/pt at 10 mT steps incl. ramp): ~13 s/pt here → 96 pts ≈ 21 min + 0 → 0.25 T ramp 2 min + gate ramps → ≈ 25 min. Ends at **1.2 T with the gates at the spot**; the fan then starts at its pinned B_lo (≤ 1 T, a < 6 min re-traverse) and ascends to 10 T.

**Checkpoints.** First ~10 rows: signal present, no rail, TG/BG currents at baseline, field readback tracking 1/B setpoints. Read: `sdh_onset` on the joined record (this run + run 6 above 1 T) → the 7.1 T tone's onset is the fan's B_lo.
