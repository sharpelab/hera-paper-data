## HERA — Step 4: Landau fan, electron side (`landau-fan-vti`), D = 0, n = +3.25 → +1.00×10¹², B 0.7 → 8 T

**Why this fan.** The spot checks (runs 6/7, read in ana) already carry the shape of the answer: run 6 (electron, n = +3.2×10¹², FFT 1.0–3.0 T) shows **7.5, 22.5 and 29.9 T** with 15.0 T = 2×7.5 — a pair f₁ + f₂ = 30.0 T = **0.91 F_L** plus a tone at the sum (the symmetry-allowed ABAB inter-block breakdown / sum tone the investigation says to *expect*); run 7 (hole, n = −1.2×10¹²) gives 4.7 + 6.6 = 11.3 T = **0.91 F_L** — the same global density scale on both sides, consistent with a lever-arm prior 9 % high. The model (`fs_count_b0`, electron side) predicts ABAB 7.3/25.8 T (0.22/0.78) vs ABCA 33.1 T at this n, so the spot check leans ABAB — but a single density cannot separate "pair + breakdown" from mixed domains, and the partition-vs-density trajectory is the investigation's Step 5 evidence: on ABAB the light pocket **empties toward n ≈ 1×10¹²** (model: 0.6 T at n = 1.0, 7.5 T at 3.25; heavy fraction 0.95 → 0.78) while an ABCA singleton stays pinned at F_L. That trajectory is what this fan buys, on the side (electron) that reaches the design densities — the hole side of the D = 0 line ends at −1.27×10¹² inside the validators, in the near-CNP balanced-pair exception regime.

**Design (computed, landau-fan step 1).** Per-column SdH-FFT fan → slow axis **uniform in 1/B**: Δ(1/B) = 1/(3 × 34 T) = 0.0098 T⁻¹ (3 rows/period on F_L at n = 3.25 nominal, ≥ 2.6 on a region-B sum tone up to 34 T; Nyquist 51 T, so the 45 T heavy-tone 2nd harmonic does not alias) → **134 rows, 0.7 → 8 T**. B_lo = 0.7 T = this device's measured onset floor (`sdh_onset`: run 7 0.71 T; run 6 light tone still SNR ≈ 96 at its usable 1.0 T record edge, i.e. censored — the fan's 0.7–1.0 T rows pin the electron onset per column instead of a separate extension). B_hi = 8 T: rows above 6 T cost ~4 rows + 15 min and buy δF 1.63 → 1.4 T on the n = 3.2 heavy tone plus the ν = 8/12/16 ladder to n ≤ 1.55/2.3/3.1 (adjacent-N check, weak complement). n-axis: ray spacing g·eB/h = 0.068×10¹² at 0.7 T → **68 columns**, Δn = 0.034×10¹² (2.0 per ray). Partner-tone record at the low-n edge (scale 0.91): 2.8 periods at n = 1.0, 4.2 at 1.5, 5.6 at 2.0 → the ≥ 5-period partner claim holds for n ≳ 1.9×10¹²; below that the columns read the trajectory, not a resolved partner. δF = 0.77 T on the full 0.7–8 T record. Dwell 1.2 s = 4τ (τ = 0.3 s, 24 dB/oct, asserted in the cell): the fast-axis lag is a uniform ≈ 1-column shift in n (1–3 %, inside the lever-arm prior), and the SdH phase step between adjacent columns is ≤ 0.15 cycle where the heavy tone is alive (≥ 1.4 T), so the mixing attenuates amplitude ≤ 11 % without moving frequencies; 6τ would add 1.7 h. Sensitivity 50 µV (5 kΩ FS) inherited from the spot checks: worst corner n = 1.0 × 8 T (ν ≈ 5.2) vs run 7's 587 Ω at ν ≈ 5 → 8.5× headroom.

**Coverage trade, stated.** Excluded: the hole side (run 7 is the preview; a hole fan would live entirely in the exception regime); n < 1.0×10¹² (partner tone unresolvable in any window, +1 h per 0.5×10¹²); 8–10 T (+25 min for ν = 8 up to 1.9×10¹² only). Price from this session's own runs — run 5: 1.10 s/pt at fast_delay 1.0 and 5.8 s row turnaround; runs 6/7: 3.1 s per field step beyond the bare 0.137 T/min ramp — 134 × 68 × 1.3 s = 3.3 h + rows 0.3 h + ramps 1.0 h = 4.6 h, quoted **≈ 5 h** (+10 %). Ends at **8 T with the gates parked at 0 V** (the next field measurement rides the magnet down).
