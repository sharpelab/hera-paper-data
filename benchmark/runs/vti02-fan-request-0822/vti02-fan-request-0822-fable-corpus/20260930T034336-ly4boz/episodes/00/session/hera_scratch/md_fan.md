## HERA — Step 4: Landau fan, electron side (`landau-fan-vti`), D = 0, per-column SdH-FFT design

The stacking-call fan per `investigations/tetralayer-stacking-fs-count.md` Step 4, on the side the spot checks picked (ana cell 15: electron reaches n = 3.2×10¹² where the templates separate; run 6 is clean, run 7 sits in the low-|n| exception regime). The claim this fan carries: per-column FFT tone set vs F_L, the Luttinger partition, and each tone's n-trajectory — which together resolve run 6's open fork (14/22/29.5 T content = harmonic ladder of 7.11 T vs a genuine ABAB heavy pocket: a harmonic tracks k·f exactly with n, a real pocket follows its own Onsager curve, and the pair must sum to F_L across density).

**Design numbers (computed, per `landau-fan.md` step 1 + investigation Step 2):**
- **B_lo = 0.30 T** — run 6's `sdh_onset` returns the carrying tone *censored*: onset_b = 0.30 T is the record's low edge, a valid lower bound. No low-field extension: δF = 1/(1/0.3 − 1/10) = **0.31 T** already separates everything the claim needs (ABAB-heavy vs ABCA at n_max: 7.3 T apart ≫ 2δF; partner at 7.1 T spans 23 periods ≥ 5), and pushing B_lo lower inflates N_B ∝ 1/B_lo for no binding gain.
- **B axis**: `field_invB(0.3, 10.0, 321)`, ascending (magnet sits at 0 T; ends at 10 T where the follow-ups — B-window split, LK ladder — ride it down). Δ(1/B) = 0.0101 /T → **3.0 samples/period at F_L(3.2×10¹²) = 33.1 T**, 2.6/period at 1.15·F_L (lever-arm band top); FFT Nyquist 49.5 T. Content above ~49 T (e.g. a 2nd harmonic of a 26 T heavy tone) would alias — accepted, amplitudes there are Dingle-killed.
- **n axis**: n = +1.2 → +3.2×10¹² at D = 0, **101 pts** (Δn = 0.02×10¹²), run-5 calibration → Vtg [+0.411, +0.984], Vbg [+0.425, +1.166] V, inside validators. **Deliberate trim vs the base's "N_n at B_lo" (=141):** Δn = 0.02×10¹² is ray-Nyquist at B ≥ 0.41 T, not 0.30 T — per-column FFTs are immune to n-axis sampling, and the claim's ray reads (ν = 8/12/16 layer-number ladder) live at B ≥ 3 T where Δn_ray/Δn = 14. Only the raster *visual* below 0.41 T is undersampled. Saves ~2.9 h (40 columns × 321 rows).
- **Coverage trade**: hole side excluded (TG limit caps it at −1.27×10¹², inside the exception regime — run 7 showed it non-decisive); n < 1.2×10¹² excluded (ABAB heavy sits within 5% of F_L there, partner unresolvable — template-degenerate; ~7 min/column to add back).
- **Dynamic range**: sr1 fixed **50 µV** (5 kΩ FS at 10 nA) — worst corner (n = 1.2×10¹² × 10 T) anchored by run 7's measured 0.58 kΩ at the same |n|, 10 T → ~8× headroom; locks the spot checks' sensitivity per investigation Step 3.
- **Dwell**: fast_delay = **1.2 s (4τ**, τ = 0.3 s / 24 dB**)** — a stated deviation from the base's ~6τ guidance for per-column-FFT fans: the fast-axis lag is identical for every row at a given column (same sweep history), so it cannot corrupt a column's B-record; it acts as a small one-signed n-offset common to the F(n) read, absorbed by the global scale. Run 5 (fast_delay 1.0 s, same τ) extracted cleanly. slow_delay = 1 s covers the ~0.7 s gate flyback.

**Price** (calibrated on run 5: 1.17 s/pt wall at fast_delay 1.0 → read overhead ~0.1 s/pt): grid 321×101×1.30 s = 11.7 h + traverse 0→10 T (73 min, blocking ramp distributed over rows) + 321×(3 s driver settle + 2 s flyback/slow_delay) = 27 min → **13.4 h computed, headline 14 h 30 m** (+8%, session actuals run over the bracket). Uniform-1/B puts 231 of 321 rows below 1 T: the decisive high-B content (B > 2 T, heavy-tone/harmonic fork) lands in the **final ~2.5 h**.
