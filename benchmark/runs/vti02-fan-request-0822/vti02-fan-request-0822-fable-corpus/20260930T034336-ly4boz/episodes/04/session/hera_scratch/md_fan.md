## HERA — Step 4: Landau fan, electron side (`landau-fan-vti`), D = 0, n = +1.5 → +3.2×10¹², B 0.3 → 6 T

The stacking call's decisive measurement (investigation Step 4): per-column SdH FFT across density, on the side the spot checks picked. Run 6 (n = +3.2×10¹²) resolved the light tone at 7.1 T (≈ model ABAB light pocket, 7.31 T) with content at 22.1/29.5 T that a single density cannot classify — harmonic comb of 7.1 vs the real ABAB heavy pocket (model 25.8 T) vs F_L (33.1 T). The n-trajectories separate these: harmonics track k·f_light(n) exactly (3×light = 10.7 T at n = 2.0), a heavy pocket follows its own Onsager curve (17.1 T at n = 2.0), an ABCA singleton rides F_L. Hole side excluded: validator-capped at |n| ≤ 1.27×10¹², inside the investigation's low-|n| exception regime — run 7 stands as the h-side consistency record. **Design (computed, model F(n) table + runs 6/7):**

- **B_lo = 0.30 T** — run 6's measured onset (censored at the record edge → valid lower bound; sub-0.3 rows would be bought blind).
- **B rows: uniform in 1/B, 316 rows**, Δ(1/B) = 0.01005 T⁻¹ = 1/(3.0·F_L(n_max)) — 3 samples/period at F_L = 33.1 T, 2.6 at the +15 % lever-arm band edge (38 T); Nyquist limit 49.7 T. Rows concentrate at low B where the periods live (only ~17 rows above 3 T).
- **B_max = 6.0 T** — δF is onset-limited: at n_max δF = 0.31 T; worst column (n_lo, onset ≈ 0.7 per run 7) δF = 0.79 T → 2δF = 1.6 T < the heavy-vs-F_L gap at n_lo (2.0 T). Raising B_max buys almost no δF and only feeds the weak Step-6 ladder — run 6 already covers n = 3.2 to 10 T. Heavy tone (m* ≈ 0.06) is LK-alive above ~2 T at T_e ≈ 8 K, 8.5 periods in-window.
- **n = +1.5 → +3.2×10¹², 101 columns** (Δn = 0.017×10¹²). n_lo floor: below 1.5 the light partner falls under 5 periods in any practical window (3.6 at n = 1.2) — the stated exception regime. n_max = validator edge (V_tg = +0.984, 16 mV margin). Image ray-Nyquist ≥ 2 for B ≥ 0.35 T; per-column FFTs unaffected below.
- **fast_delay 1.8 s = 6τ** (τ = 0.3 s, 24 dB/oct) — per-column FFT carries the signal on the n-axis, so the 4τ Středa dwell is not enough (base step 7). slow_delay 1 s. Sensitivity fixed 50 µV (5 kΩ FS): worst corner (n_min × 6 T) anchored by runs 6/7 ≤ ~600 Ω ≈ 12 % FS — 8× headroom, and this exact setting resolved tones at SNR ≤ 125. Leak guard 1 nA stays on.
- **Price** (calibrated: run 5 fast axis 1.10 s/pt at 1.0 s delay → reads ≈ 0.1 s; runs 6/7 settle+ramp): 316×101 pts × 1.9 s = 16.8 h + row overhead (settle 3 s + flyback ≈ 2.4 s) 0.5 h + 5.7 T ramps 0.7 h = **18.0 h computed → headline ≈ 19 h** (session evidence: actuals run over). **Ends: gates parked at 0, field at 6.0 T** — deliberately left for the LK mass split (Verify: temperature-dependence Flavor B, B window ~2.8–6 T) that follows the fan read.
- **Cost floor**: this is the floored design — B_lo at measured onset, n_max at claim validity, N_n at the F(n)-trace floor (ray floor 0.35 T stated), B_max at claim need. The one non-floor choice is Δ(1/B) at prefer-1/3 rather than 1/2-Nyquist: at 1/2 the F_L tone sits on the Nyquist edge and a +15 % scale error aliases it — not acceptable on the tone the call keys on.

**Checkpoints** (armed `hera-watch data --next --follow`): first rows ~15 min (signal, sensitivity, leakage, field tracking); ~row 60 (≈3.5 h, B ≈ 0.5 T) low-B image sanity — rays present, no rail; ~row 150 (≈8.5 h, B ≈ 0.85 T) partial per-column FFT (δF ≈ 0.67 T) — light-branch f(n) trajectory check, continue/abort; ~row 240 (≈13.5 h, B ≈ 1.6 T) heavy-tone band emerging. Abort criteria: rail, leak trip, or no oscillatory structure at the high-n columns by row 60 (run 6 guarantees it should be there — absence means a gate/cal fault).
