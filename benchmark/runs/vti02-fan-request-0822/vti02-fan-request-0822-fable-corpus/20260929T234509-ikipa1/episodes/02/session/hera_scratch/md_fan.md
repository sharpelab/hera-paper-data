## HERA — Step 4: Landau fan, electron side at D = 0 (`landau-fan-vti`) — the stacking-call dataset

**Why this fan (investigation Step 4, inheriting run 6/7 spot checks — see ana).** Run 6 (electron, n = +3.2×10¹²) left a fork the n-dependence decides: 7.1 + 22.1 T sum to 0.88·F_L with an ABAB-like 0.24/0.76 partition, but 22.1 ≈ 3×7.1 — real heavy pocket vs 3rd harmonic. Across the fan a harmonic tracks 3×f₁ exactly, a real heavy tone follows its own Onsager curve (model: light tone dives 7.3 → 1.1 T over n = 3.2 → 1.2×10¹² while the heavy tone stays near F_L) — the trajectories diverge unmistakably. Hole side stays a preview (run 7): gate limits cap it at |n| ≤ 1.27×10¹², inside the model's balanced-pair exception regime — a hole fan would be uninformative, that's the coverage trade.

**Design (computed, `landau-fan.md` step 1 + VTI variant cost regime):**
- **Fast axis**: n = +3.2 → +1.2×10¹² cm⁻² at D = 0 (run-5 cal), **141 pts** (Δn = 1.43×10¹⁰ ≤ half the ray spacing 2.90×10¹⁰ at B_lo = 0.3 T). Vtg +0.984 → +0.411, Vbg +1.166 → +0.425 V — inside validators. n_min = 1.2×10¹²: the ABAB partner needs ≥5 periods, resolvable only for n ≳ 1.35×10¹² (model f_partner); below that columns are exception-regime background — the low-n claim floors there.
- **Slow axis**: **B 10 → 0.3 T uniform in 1/B, Δ(1/B) = 0.0121 T⁻¹ → 269 rows.** Nyquist 41.3 T covers the coherent content observed in run 6 (≤ 32.4 T; ≤7% noise-floor above 36 T) with 2.5× margin on F_L(n_max) = 33.1 T. δF = 0.31 T over the 0.3–10 T record; the binding split (22.1 vs 3×7.1 = 0.8 T) is 2.6·δF. B_lo = 0.3 T = run 6's censored onset lower bound (raising it would kill the harmonic-vs-heavy split; lowering it inflates both axes' floors).
- **Direction**: descending — magnet pre-ramps 0 → 10 T (bare, blocking, ~73 min), fan rides home 10 → 0.3 T and **ends at 0.3 T**. This puts the worst dynamic-range corner (n = 1.2×10¹² × 10 T, measured by run 7: 587 Ω = 12% of FS) **in the first row** — the cheapest possible kill for a sensitivity mistake — and lands the FFT-grade high-B record in the first ~3 h instead of the last.
- **Sensitivity/settling inherited from the spot checks**: sr1 50 µV (5 kΩ FS), τ = 0.3 s / 24 dB; fast_delay = 1.2 s (4τ — the retrace lag is static per column and removed by the per-column background; the residual n-smear is < δF; the 2026-06-14 VTI trilayer fan idiom), slow_delay = 1. Leak trip 1 nA.
- **Price** (calibrated: run 5 fast-axis 1.10 s/pt at fast_delay 1.0 → 1.3 s/pt here; runs 6/7 field overhead 3.08 s/row): pre-ramp 73 min + in-fan traverse 71 min + 269 settles 14 min + grid 269×141×1.3 s = 13.7 h + turnaround ~9 min ≈ 16.4 h; realistic **~17.5 h**.

**Checkpoints** (hera-watch armed on the run dir): (1) **first row ~75 min in** (after the pre-ramp): rail/clip across the full n-line at 10 T, leakage, both channels live; (2) **~4 h**: high-B record (B ≳ 2 T, rows 1–33) per-column FFT — heavy-tone F(n) trajectory, the early template read; abort/redesign if the 22.1 T tone is absent across all n; (3) every ~3–4 h: light-tone F(n) on the growing 1/B record, T_sample at base, leakage. Magnet ends at 0.3 T, gates park at 0.
