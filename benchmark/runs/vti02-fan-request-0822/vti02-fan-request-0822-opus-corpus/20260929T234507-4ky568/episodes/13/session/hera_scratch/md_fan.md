## HERA — Step 4: Landau fan at D = 0, **electron side** (`landau-fan-vti`), n = +3.20 → +1.50×10¹², B 0.8 → 10 T

**Step 3 read (runs 6, 7) — the input to this design.** Both spot checks are complete and clean; their ana cells land while this fan runs.

- **Run 6** (electron, n = +3.2×10¹², F_L = 33.1 T): `sdh_onset` → `onset_b = 0.30 T`, **censored at the record's low edge** — oscillations persist below the sweep floor. Tone set {3.0, 4.2, 5.2, **7.1**, 9.5, 14.1, 22.2, 29.5} T at SNR 23–101; R_max 530 Ω = 10.6 % of full scale, no clipping. 7.1 T is the fundamental; 14.1 / 22.2 / 29.5 are flagged 2× / 3× / 4×.
- **Run 7** (hole, n = −1.2×10¹², F_L = 12.4 T): `onset_b = 0.71 T`, and the peak set **wanders with the low-B cutoff** — dominant peak 6.8 → 7.8 → 5.3 → 5.0 T across cutoffs 0.5 / 1.0 / 1.5 / 2.0 T. That is the FFT-stability artifact signature, in the near-CNP semimetal regime the investigation flags as an exception; the TG limit also caps this side at |n| ≤ 1.27×10¹², below the |n| ≳ 2–3×10¹² where the templates separate.
- **Side call: electron** — lower onset, stable peak set, and the only side with design-density reach. **Coverage trade, stated:** the hole side is excluded from the fan. Its price would be a second ~4.5 h fan, and by run 7 it cannot carry a classification-grade read at any density the gates reach. It stays in the hedges (Step 7 part 3), not in the evidence.

**Why a fan and not a verdict from run 6.** The model (`tetralayer_fs_count/fs_count_b0`) at n = +3.2×10¹² predicts **ABAB {7.3, 25.8} T** against **ABCA {33.1} T** — and heavy/light = 3.5, so the ABAB heavy tone sits *between* the 3× and 4× harmonics of its own partner. Run 6's 22.2 and 29.5 T peaks straddle 25.8 T and neither is separable from the comb on one column. The recipe's rule applies verbatim — the ratio cannot screen this; "the n-dependence screen plus the sum decide". Across this fan's window the trajectories diverge and that degeneracy breaks: model ABAB partner rises **2.04 → 7.30 T** (0.13 → 0.22·F_L) while 3×partner runs 6.1 → 21.9 T and the heavy tone runs 13.5 → 25.8 T — a harmonic tracks k·f₁(n) exactly, a pocket follows its own Onsager curve. ABCA predicts one tone on F_L(n) and **no low tone at all**. That is the read this fan delivers, and it is Step 5 (partition robustness + branch labeling) in the same object.

**Design — `landau-fan` step 1, computed, not eyeballed:**

- **Fast axis** n = +3.20 → +1.50×10¹² at D = 0, **50 columns**, Δn = 0.0347×10¹² (V_tg +0.9836 → +0.4966, V_bg +1.1847 → +0.5359; 16 mV under the TG limit). Floor is the ray Nyquist at B_lo: Δn_ray = 4(e/h)·0.8 T = 0.0774×10¹² → **2.2 pts/ray**, above the ≥ 2 floor. The low edge is physics, not budget — below n = 1.5×10¹² the model templates are degenerate (heavy → 0.95·F_L, partner → 0.6 T, unresolvable in any window).
- **Slow axis** B 0.8 → 10 T **uniform in 1/B** (`field_invB`), **117 rows**, Δ(1/B) = 0.00991 1/T — the prefer-1/3 target on F_L(n_max) = 33.1 T (Nyquist 49.9 T).
- **B_lo = 0.8 T, set by resolution, not by the onset.** The carrying tone's onset is *censored*, so 0.30 T is a lower bound on the record, not a measured die-off — the binding case is instead separating the heavy tone from 3×/4×partner (Δ ≈ 3.5–4 T at n_max): needs 2δF < 3.5 T. At B_lo = 0.8, 1/B span = 1.150 → **δF = 0.87 T (2δF = 1.74 T)**, and the mandatory **B-window split** (F_L-tone origin, Verify) still gives δF = 1.74 T per half. B_lo = 1.2 T would pass the whole-record check and fail the split — that is what buys the extra 25 rows.
- **Partner period count** over the record: 8.4 periods at n = 3.2, 5.9 at 2.5, 4.1 at 2.0, 2.3 at 1.5. The partner claim is therefore resolvable for n ≳ 2.2×10¹² and **floored below that** — a hedge to report, not something more field fixes (raising B_max past 10 T adds < 10 % of span).
- **Dynamic range**, worst corner n_min × B_max: R(B = 0, n = 1.5×10¹²) = 84 Ω (run 5 gate map) × run 6's measured MR factor 7.6 ⇒ ~0.9–1.2 kΩ, ≈ 20 % of the 5 kΩ full scale at sr1 **50 µV**. Held at the spot checks' sensitivity: run 6 delivered SNR 23–101 while sitting at 1.4 % FS, so the high-n corner is not ADC-limited, and this session's run-4 rail is the standing argument for sizing the worst corner rather than the typical one.
- **Settling** `fast_delay = 1.8 s` = 6τ (τ = 0.3 s, 24 dB/oct) — the `landau-fan` per-column-FFT value; `slow_delay = 2.0 s` covers the 0.5 V row-start gate flyback, so the first column of each row gets 3.8 s > 10τ.
- **Grid-change reproduction (Verify, free).** The top column sits at n = +3.20×10¹² — run 6's exact spot — sampled uniform-in-1/B here against uniform-in-B there. Any tone that moves between the two is a sampling alias, which retires one of the three F_L-tone-origin branches without a dedicated run.
- **Direction.** Ascending from 0.8 T, where the magnet effectively sits (0.003 T); ends at **10 T** with the gates at n = 1.5×10¹², so the LK mass split (Verify, in-arc) rides the magnet back down rather than re-traversing.

**Price.** 9.2 T traverse 67 min + 5850 pts × ~1.92 s = 187 min + 117 rows × ~6 s = 12 min ⇒ **≈ 4 h 26 m**, calibrated on run 5 (gate map, `fast_delay` 1.0 s, 1.171 s/pt ⇒ ~0.10 s/pt read overhead at NPLC = 1). Headline 4 h 45 m allows this session's observed 5–10 % overrun.

**Checkpoints.** First 3 rows — leakage, rail, signal amplitude, field tracking the setpoints. Then ~row 30 (B ≈ 1.2 T) and ~row 80 (B ≈ 3.5 T): partial per-column FFT on the landed rows — abort if any column rails, or if the 7.1 T tone fails to reproduce at the n = 3.2 column. In-cell guards trip the sweep on gate leakage > 1 nA or T_sample outside [1.0, 1.6] K, each requiring 3 consecutive points so the row-start flyback transient (session note, run 4/5) cannot false-fire.
