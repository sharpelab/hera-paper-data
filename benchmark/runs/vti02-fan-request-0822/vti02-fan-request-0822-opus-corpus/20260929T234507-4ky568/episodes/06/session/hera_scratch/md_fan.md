## HERA — Step 4: Landau fan (`landau-fan-vti`), D = 0, n = +1.60 → +3.20×10¹², B 0.7 → 7 T uniform-1/B

**Why a fan, and what it has to settle.** Run 6 (electron spot check, n = +3.2×10¹², F_L = 33.1 T) is a strong, stable four-peak set: **7.2 / 14.2 / 22.1 / 29.5 T**, reproducing to <0.5 % in frequency across `bg_degree` 3/5/7 and windows 0.8–7 / 1–7 / 1.5–7 / 1–5 / 1–10 / 2–10 T (`hera_scratch/ana_spot2.py`). It admits two readings that a single density **cannot** separate, and this is the Luttinger-aware harmonic-screen trap the investigation names explicitly:

- **harmonic comb** — one tone at 7.2 T with 2×/3×/4× harmonics. Ratio 22.1/7.2 = **3.01**, i.e. the screen's "ratio drifts through 3×" coincidence exactly. But a lone 7.2 T pocket is 0.22·F_L: the Luttinger sum needs a global density rescale of 0.22, far outside the lever-arm band (0.8–1.2), so this reading is already disfavoured *on the sum*, not on taste.
- **an ABAB pair** — {7.2, 22.1} summing to 29.3 ≈ 0.89·F_L (scale inside the prior band), with 14.2 = 2×light and **29.5 = 7.2 + 22.1 the symmetry-allowed inter-block breakdown / sum tone** — which by construction lands at the rescaled F_L and mimics an ABCA singleton. Model (`fs_count_b0`, ABAB at n = +3.2×10¹²): **7.31 / 25.78 T** — the light branch matches to 1 %. A competing pairing {7.2, 29.5} (sum 1.11·F_L) is also pair-shaped. All of them are *two Fermi surfaces*; none is an ABCA singleton, since a singleton cannot produce a 7.2 T partner at SNR 40.

**The discriminator is the n-trajectory, and only a fan gives it.** A harmonic sits at exactly k·f at *every* density; the ABAB partition moves — model f_heavy/f_light runs **3.53 → 4.82 → 6.59** at n = 3.2 → 2.0 → 1.5×10¹². Per-column F(n) across 49 densities, checked against both the ABAB and ABCA model curves under **one** global scale, plus the Luttinger sum, is the investigation's Step 4/5. Aliased harmonics are screened too: a fold-back moves *opposite* to n, a real pocket tracks with it.

**Design numbers (Step 2 / `landau-fan` step 1, computed not eyeballed).** Fastest expected tone = F_L(n_max) = 33.1 T → Δ(1/B) ≤ 1/(3·F_L) = 0.0101; committed **Δ(1/B) = 0.00752** (4.0 pts/period at F_L, Nyquist 66.5 T). Tighter than the 1/3 rule on purpose: replaying run 6 through candidate fan grids (`ana_spot2` sibling check) shows Δ(1/B) = 0.010 inflates a minor 17.5 T feature to 0.39 of the fundamental vs 0.27 on a 0.002 reference — a fold-back of the ~80 T comb members landing **in the heavy-branch band**. At 0.00752 the peak set matches the fine reference. n-axis: Δn = 0.0333×10¹² = **2.03 rays/period** at B_lo (≥2 floor). **B_lo = 0.7 T**: run 6's `sdh_onset` is 0.30 T but *censored* (oscillations persist to the record edge), so 0.30 is a lower bound only; 0.7 T is the cost floor — the n-axis Nyquist couples to B_lo, and 0.3 T would demand 320 rows × 111 columns ≈ 13 h. **B_max = 7 T**: the 1/B record is 1.286 T⁻¹, and extending to 10 T adds 3 % to it (δF 0.778 → 0.753 T) while costing 22 min of traverse and forcing headroom for the 8–9 T QH peak — no. δF = **0.78 T**, so the ≥5-periods-on-the-partner criterion holds for f_partner ≥ 3.9 T, i.e. the **two-tone partition claim window is n ≥ ~2.2×10¹²**; columns 1.6–2.2 carry the heavy branch only and their light-tone absence will be reported as *not-resolvable*, not *absent*.

**Dynamic range.** Fixed **sr1 = 50 µV (5 kΩ FS at I_bias = 10 nA)** — same as runs 6/7, so columns are directly comparable. Worst corner is low n × high B: R(B = 0) at n = 1.6 is 82.9 Ω (run 5) vs 55.9 Ω at n = 3.2, and run 6's MR/SdH maximum was 522 Ω → expect ~1.2–1.5 kΩ at (1.6×10¹², 7 T), ~3.5× under full scale. 20 µV (2 kΩ) would be a gamble on an extrapolation and clipping is unrecoverable.

**Settling, stated because it is the cost lever.** τ = 0.3 s at 24 dB/oct; `slow_delay = 3.0` s (10τ, on top of the magnet's blocking set + 3 s `settle_s`) covers the big flyback from n_max back to n_min. `fast_delay = 1.2` s is **4τ**, below the recipe's 6τ for a per-column-FFT fan, and the reason is specific to this geometry: the extracted signal runs along **B**, sampled once per row with a whole row plus a magnet ramp in between — it carries no fast-axis lag at all. The fast-axis residual (4-pole, 43 % per step) only mixes column j with column j−1, which are **1 % apart in n**; the net effect is a rigid ≈0.76-column (0.8 % in n) shift of F(n), far inside the 10–15 % lever-arm prior and not a distortion of the trajectory. 6τ would cost +1.1 h for that. **This is checkpointed, not assumed** — see below.

**Price:** 172 rows × 49 columns = 8428 pts at ~1.35 s/pt (run 5 calibration: 4158 pts / 4873 s = 1.17 s/pt at `fast_delay` 1.0) = 3.2 h, + 6.3 T blocking traverse 46 min, + 172 × ~7 s row overhead 21 min → **≈ 4 h 45 m**, ending at **7 T with gates parked at 0** — deliberate: the LK mass split (Verify) rides the magnet back down.

**Checkpoints (both armed on `hera-watch data --next --follow`).** (1) *First rows*, ~0.7 T: R in the 60–200 Ω band, no rail, both gate columns moving, gate currents at the flyback-transient baseline, T_sample 1.1–1.4 K — abort in the first minute if not. (2) *~row 86, ≈2 h in* (B reaches 1.27 T, half the 1/B record): FFT the n = +3.20 column over the landed 0.7–1.27 T window and compare tone amplitudes against **run 6 restricted to the same window** — run 6 was taken at the full 10τ settle, so this is a direct empirical test of the 4τ choice *and* the grid-change reproduction the Verify asks for. If the fan's tones are materially attenuated relative to run 6, I stop and re-run at 6τ rather than spend the remaining 2.7 h.

**Guard:** `register_run_after` trips the run on |I_gate| > 1 nA or T_sample > 2.0 K.
