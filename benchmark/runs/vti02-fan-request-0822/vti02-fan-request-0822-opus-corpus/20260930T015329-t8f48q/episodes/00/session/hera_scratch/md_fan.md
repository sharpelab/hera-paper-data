## HERA — Step 4: Landau fan, electron side, D = 0 (`landau-fan-vti`) — the stacking call

**Side: electron.** Run 6 (n = +3.2×10¹², D = 0) is dramatically the cleaner spot check — SdH minima reach ~0 Ω from ~1.5 T up, `sdh_onset` tracks tones to the record's low edge (onset_b = 0.30 T, **censored** — the oscillations never died in the window, so 0.30 T is a lower bound, not a measured onset), peak SNR 40–90. Run 7 (hole, n = −1.2×10¹²) onsets at 0.71 T with a muddier, lower-SNR set and sits in the investigation's near-CNP exception regime. The D = 0 line is TG-limited at n = −1.27 … +3.27×10¹², so the hole side cannot reach the |n| ≳ 2–3×10¹² design window at all. Fan goes electron.

**What run 6 already says (drives the design).** Per-column FFT of run 6 is a full comb on f₀ ≈ 7.5 T: 7.5 / 15.0 / 22.5 / **29.9** / 37.4 / 44.9 / 52.4 / 59.9 / 74.9 / 89.8 T, dominant at 29.9. Two readings survive: (a) **two fundamentals** f_light ≈ 7.5 and f_heavy ≈ 29.9 with the rest intermodulation/harmonics of a strongly non-sinusoidal Rxx — their sum 37.4 T closes the Luttinger sum under **one global scale 1.13** (F_L^nominal(3.2) = 33.1 T), partition 0.20/0.80 against the model's 0.225/0.775 at that density → **ABAB pair**; (b) a **singleton at 29.9 = 0.90·F_L** (scale 0.90, also inside the 0.8–1.2 lever-arm band) → ABCA, with the 7.5 T tone then needing the mandatory F_L-tone-origin discrimination. A scale of 1.13 is independently plausible: the gatemap already moved c_bg/c_tg −11 % off the geometry prior, and c_tg is still the bare 9.5 nm prior. **This fan is the discriminator**, via two n-dependence tests a single column cannot do: (1) partition robustness — f₁(n) + f₂(n) = F_L(n) at **one** global scale across the whole window; (2) the ratio trajectory — the model's ABAB f_heavy/f_light drifts **4.83 (n = 2.0) → 3.49 (n = 3.27)** while a harmonic comb is pinned at exactly 4.000, and the dominant-tone fraction f_heavy/F_L drifts 0.828 → 0.777 while an ABCA singleton stays at 1.000. The comb sits right at 4×, so the ratio-only screen is exactly the trap the investigation warns about — the n-dependence screen plus the sum decide.

**Design numbers** (`landau-fan` Recipe 1, computed not eyeballed; model table from `hera/models/tetralayer_fs_count/fs_count_b0.py`):
- **n = +1.50 → +3.25×10¹² at D = 0, 45 columns** (Δn = 0.0398×10¹²). n_max is the TG limit: V_tg = +0.9979 V, 2.1 mV under the +1.0 V validator. **n-axis Nyquist** at the lowest read field: ray spacing Δn = 4(e/h)·B_lo = 0.0967×10¹² at 1.0 T → **2.43 points/ray**, clears the ≥2 floor.
- **B = 1.0 → 10.0 T, uniform in 1/B, 145 rows**, Δ(1/B) = 6.25×10⁻³ T⁻¹ → **Nyquist at 80 T**. Not the textbook 1/(3·F_L) = 9.9×10⁻³ (Nyquist 50 T): run 6 *measures* real comb power out to 60 T (amp 0.29) and 90 T (0.10), and at Nyquist 50 T the 74.9 T member folds onto 25 T — straight into the heavy-tone band. At 80 T everything above the cut folds to ≥43 T, leaving the 0–35 T classification band alias-free against all measured content.
- **B_lo = 1.0 T is set by the claim, not the onset** (the onset is censored below 0.3 T, so it binds nothing and a lower B_lo would inflate *both* axes). It gives **δF = 1/(1/1 − 1/10) = 1.11 T**: the ABAB-heavy-vs-F_L gap is 3.55 T at n = 2.0 and 7.5 T at n = 3.25, i.e. ≥ 3.2·δF everywhere — the dominant-tone test holds across the whole window. **Coverage trade, stated:** the ≥5-periods rule on the *partner* tone (f_light = 3.55 T at n = 2.0) needs B_lo ≤ 0.66 T, which would cost ~10 h (both N_B and N_n scale with 1/B_lo). So the **partition claim is floored at n ≥ 2.4×10¹²** (≥5 partner periods); columns n = 2.0–2.4 give a broad partner peak (3.2 periods) and 1.5–2.0 are trajectory context only, approaching the low-density regime where ABAB legitimately mimics ABCA. The high-resolution partner anchor already exists — run 6 at δF = 0.31 T. Cheap targeted low-n spot checks are the follow-up if the partition needs firming below 2.4, not a 2× more expensive fan now.

Inherited from the spot check, unchanged.
