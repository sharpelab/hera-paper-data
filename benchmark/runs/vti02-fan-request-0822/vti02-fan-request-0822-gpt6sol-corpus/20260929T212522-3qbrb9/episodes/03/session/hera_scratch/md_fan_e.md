## HERA — electron D = 0 Landau fan for the stacking count (`landau-fan-vti`)

Runs 6/7 and the ana notebook's raw→FFT reads show that the electron side carries a strong 7/14/22/30 T comb at n = +3.2×10¹², whereas the hole side is confined by the TG limit to the model's close-tone exception near −1.2×10¹². A single density cannot tell whether the electron comb contains an independent ABAB partner, harmonics, or a F_L sum/breakdown tone. The fan tracks each frequency across n on the only wired four-terminal pair, B_1–B_2, using run-5 calibration (ratio 0.773 data-calibrated; absolute density geometry-prior). Region B's parallel CNP is offset by +0.43×10¹² relative to A, so extra branches must be tested against a *shared* scale and a shifted density before any domain claim.

**Feasibility and coverage.** D = 0, n = +2.4…+3.2×10¹² (25 points, Δn = 0.0333×10¹²) maps to V_tg = +0.7544…+0.9836 V, V_bg = +0.8697…+1.1663 V, inside [−0.3,+1.0]/[−1.3,+2.0]. The model ABAB light/heavy frequencies run 4.79/20.03 → 7.31/25.78 T; ABCA F_L runs 24.8→33.1 T. With B = 0.7→10 T, Δ(1/B) record = 1.3286 T⁻¹ and δF = 0.75 T, giving **6.36 periods** of the smallest light branch and >2δF separation of ABAB's heavy branch from F_L throughout. The 133 field rows give Δ(1/B) = 0.010065 T⁻¹, or ~3.0 points per F_L period at n_max; the 25 density points give 2.03 points per filling ray at B_min (ray spacing 0.0677×10¹²). The 0.3 T onset returned for run 6's 7.1 T tone is **censored at the analysis edge**, so onset below 0.7 T is unresolved. This fan excludes that sub-0.7 T tail, lower electron densities, and the hole side; full D = 0 electron coverage would cost more grid points and enter the low-n ABAB/ABCA mimic regime without improving this first count.
