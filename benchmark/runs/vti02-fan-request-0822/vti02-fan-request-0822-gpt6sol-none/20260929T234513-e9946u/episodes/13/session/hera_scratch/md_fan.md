## HERA — Step 4: D = 0 Landau fan across both carrier signs (`landau-fan`)

Plan step 4. Run 5 calibrates the main ridge with c_bg/c_tg = 0.773, n_offset = −0.0894 × 10¹² cm⁻² and D_offset = −0.013 V/nm; the density scale retains the 9.5 nm hBN geometry prior. Run 6 at n = +3.2 × 10¹² cm⁻² has strong SdH components near 7.2 and 22.2 T (plus harmonics), which need density trajectories to identify separate pockets; run 7 at n = −1.2 × 10¹² cm⁻² has multiple low-frequency components and is not decisive alone. The supplied B_1–B_2 pair is the only wired voltage region, so this fan supports one region verdict.

At base T with Si = 0, sweep calibrated D = 0 from n = −1.2 to +3.2 × 10¹² cm⁻² in 0.05 × 10¹² steps (89 points; TG/BG co-swept, both inside the committed validators). Sweep field as the slow axis from its handed-off 0 T state to 10 T in 0.25 T rows (41 rows; no return traverse). The 3 s fast-point dwell is 10 × the measured 0.3 s lock-in τ at 24 dB/oct; 500 µV sensitivity gives 50 kΩ nominal R full scale at the 10 nA drive and headroom near the CNP. Record drain current, B_1–B_2 X/phase, TG/BG currents, and both temperatures. The code prints actual preconditions and stops on mismatch; 1 nA leakage or 90% voltage full-scale trips the sweep. The slower 0.25 T field sampling and 0.05 × 10¹² density pixels trade fine anticrossing resolution for full two-sign coverage in one traverse; if branches are visible but aliased, a targeted second pass can resolve them.

Price: 10 T / 0.137 T/min = 73 min magnet floor; 41 × 89 × (3 s dwell + ≈0.3 s read/setting) ≈ 3 h 21 min, plus driver field settles, gate flyback and run overhead. Allow **5 h 15 min** based on the conservative overhead seen in runs 6–7 (run 6: 921 points, 2 h 00 min; run 7: 486 points, 1 h 36 min). Check the first 2–3 landed rows for leakage, clipping, live current and moving Rxx; then at roughly 2, 4, 6 and 8 T inspect the live digests and complete-row map. Stop if the channel rails, leakage persists, or the fan has no useful contrast; otherwise continue to 10 T and analyze before choosing a follow-up. Do not interrupt a magnet ramp as a way to stop it: the supply will continue to its last target.
