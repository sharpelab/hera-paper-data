## HERA — Step 3: base-T Landau fan on the calibrated D_A = 0 line (`landau-fan`)

Runs 6–7 show clear SdH oscillations on both signs, but spot spectra cannot separate Landau ladders, harmonics, and the second CNP region. This fan follows run 5's region-A D = 0 calibration across **n_A = −1.2 … +3.2 ×10¹² cm⁻²**, including both 0 T ridges, and B = 1.5→10 T. Region B is offset by about +0.43×10¹² cm⁻² on this scale; the map will test whether two line families follow that offset. The absolute density conversion still inherits the top-gate thickness prior, so filling slopes will be an independent scale check. Only the hardwired B_1–B_2 pair is measured.

The grid is 111 density points (0.04×10¹² cm⁻² spacing) × 44 field rows (0.2 T through 9.9 T, then 10 T), with 2.1 s per gate point (7× the measured 0.3 s / 24 dB lock-in time constant). Sensitivity is 200 µV (about 20 kΩ at 10 nA), with a 90% soft-clip stop and 1 nA gate-current trip. The field starts at the verified 0 T handoff: the 10 T traverse has a **73 min bare ramp floor** (0.137 T/min). Run 5 took 81 min for 4,158 points at 1 s dwell, giving ~0.17 s additional per point; 4,884 fan points at 2.1 s dwell cost ~3 h 5 m, plus ramp/turnaround and overhead. Planned duration is ~4 h 45 m.

**Coverage trade:** B <1.5 T is omitted from the 2D fan to save rows where the run-6/7 1D traces already cover the low-field oscillations; this gives up a low-B density map and any onset below 1.5 T. Check the first two landed rows for leakage, clipping, a dead current/voltage channel, and readback; then inspect partial maps near 3, 5, and 7 T. Stop for a persistent rail or wash-out and analyze the partial run before deciding on a repeat. The magnet's set blocks and an interrupt does not stop its supply ramp, so any field anomaly is an operator-at-instrument stop.
