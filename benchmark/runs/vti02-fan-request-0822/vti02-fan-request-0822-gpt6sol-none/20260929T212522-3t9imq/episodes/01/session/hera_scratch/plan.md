# vti-02 stacking campaign — working plan

Goal: make an evidence-cited stacking call for the only hardwired longitudinal pair, B_1–B_2, or say cannot tell. The two CNP ridges in this series path may represent separate regions; the single voltage pair does not spatially isolate them.

1. **Bring-up and safety** (complete): operator ran setup and SAFETIES; kernel-binding probe and VERIFY green; E1 grant recorded in `session_notes.md`.
2. **Gate C and calibration** (complete): runs 0–3 establish liveness and leakage; run 5 maps two CNP ridges. The main ridge's slope gives c_bg/c_tg=0.773, while absolute c_tg remains the 9.5 nm geometry prior. Run 5 yields n_offset=-0.0894 ×10^12 cm^-2 and D_offset=-0.013 V/nm. The second ridge is offset by about -0.43 ×10^12 cm^-2; keep this series-region ambiguity explicit.
3. **SdH feasibility** (complete): runs 6 (+3.2 ×10^12, D=0) and 7 (-1.2 ×10^12, D=0) show oscillatory Rxx and stable drain current. Analyze raw traces and window-sensitive spectra in ana before trusting tone assignments. The fan should track branches across density: a single trace cannot separate a Fermi pocket from a harmonic or a second region.
4. **First Landau fan** (next): field slow, calibrated D=0 density line fast, electron side where run 6 has clear contrast. Start from actual B≈0; cover B through 10 T without retraversing, inside SAFETIES. Choose the n window and spacing to resolve low-field ridges yet keep duration proportionate. Follow both gate currents, drain current, and Rxx; abort at first rows for rails/leakage/dead channel, then checkpoint at roughly 3, 6 and 8 T. Plot raw Rxx(B,n), then derivative/branch slopes and compare to 4-fold full-density filling and the two CNP offsets. If one fundamental series and zero-mode pattern is clear, compare ABCA; if two independent fan branches/pockets are robust and not just a 0.43e12 offset mosaic, compare ABAB/ABCB. No assignment from peak count alone.
5. **Disambiguation only if needed**: use a focused complementary D slice or hole-side fan based on first fan branch topology and the actual remaining uncertainty. D sweeps can reveal gap/zero-mode evolution; a temperature ladder is possible only if cyclotron gaps demand it. State coverage and cost before each step.
6. **Call and close-out**: final ana cell has one line per measured pair, numeric evidence by run id, strength, and hedges. Then execute the requested return-to-initial: B=0, TG/BG/Si=0 at committed pacing, both heater ranges off, and read back field/gates/T into `session_notes.md`.

Method controls: no prior-session data; no gate-limit probing, no standalone Si survey, no route changes. All field/gate sets stay in committed validators. Only B_1–B_2 is wired; region A/B information from its series path is not contact-resolved.
