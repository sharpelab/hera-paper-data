# vti-02 stacking-order session plan (updated after runs 0–7)

## State and measurement order

1. **Bring-up / gates A and B — done.** Setup and SAFETIES executed in the current kernel. Operator grant and `VERIFY: ALL GREEN` are recorded in `session_notes.md`; the post-handoff kernel probe reports BOUND. Current handoff state is B ≈ 0 T, gates 0 V, heaters off.
2. **Gate C — done (data/0–3).** Four short TG/BG legs at B = 0 and Si = 0 found live B1–B2 voltage and no sustained gate leakage. They revealed two resistance peaks.
3. **CNP and D calibration — done (data/5; data/4 aborted on a rail).** The 0 T map establishes the main CNP ridge A, weaker parallel ridge B, ratio c_bg/c_tg = 0.773, ridge-A n_offset = −0.0894 ×10¹² cm⁻², and D_offset = −0.013 V/nm from the ridge-resistance minimum. Absolute density remains tied to the hBN thickness prior, pending quantum-oscillation cross-check. The second ridge is offset by about 0.43 ×10¹² cm⁻² and can add parallel fan branches.
4. **SdH feasibility checks — done (data/6–7).** Electron spot at n_A = +3.2 ×10¹² cm⁻² and hole spot at −1.2, D_A = 0. Both show oscillations. Electron FFT features near 7, 15, 22–23, 30 T can be harmonics of ~7–8 T or independent pockets; hole features near 5 and 12 T are likewise not yet a stacking verdict. Their low-field onset makes a fan from ~0.3 T useful, but the stacking read will use coherent trajectories at B ≳ 1 T.
5. **Landau fan — next.** At V_Si = 0 and calibrated D_A = 0, sweep the two gate voltages together along n_A = −1.15 to +3.2 ×10¹² cm⁻² (about 0.05 ×10¹² steps), field as the slow axis from 0.3 to 10 T (about 0.2 T steps), with B increasing from the handoff 0 T. This covers both signs and the CNP while staying inside the TG/BG validators. Record actual gate currents, T, drain current, Rxx voltage and phases. Fixed D is chosen so fan branches are indexed against one density axis. A fixed sensitivity with enough headroom for the high-field CNP is required; check early rows and the first high-field CNP row for rail or current loss. Re-form the 2D map from data, plot raw values before resistance, and trace minima/periodic branches versus n and B. Quantitatively compare slopes and frequency closure against a full-density 4-fold fan, split pockets, and the two-domain CNP offset. The number, continuity, and intercept of distinct branches across n decide whether ABAB, ABCA, or ABCB has unique support. Distinguish harmonics by their integer frequency relation and shared n dependence; do not infer independent pockets from FFT peaks alone.
6. **If fan is ambiguous, targeted follow-up.** Choose one or two fixed-D cuts where its branches differ most, or a small D comparison inside validators, with a price and checkpoint. If contact-mosaic contributions cannot be separated or the sole B1–B2 pair cannot resolve them, report `cannot tell` with specific limits rather than assigning a stacking from generic gapping or a single FFT.
7. **Close out.** Return field and all gates to 0, turn both heater ranges off, print actual readback, record it in `session_notes.md`, and put the per-contact verdict and evidence in the final ana cell.

## Decisions that change the plan

- Abort a data run on sustained TG/BG leakage >1 nA, a railed Rxx channel, implausible drain current, stale thermometry, or a field/temperature mismatch. Because a magnet setpoint continues after a kernel interrupt, an active ramp requires operator handling; read actual B before any next move.
- The fixed-D fan gives only one hardwired Rxx pair. Its result is region-resolved only to that pair. If two spatial regions mix in the same voltage leads, state that limitation explicitly.
- Gate offsets and the absolute n scale carry map-fit/geometry uncertainty. Use fan spacing to check the absolute scale before treating a modest frequency mismatch as topology.
