## Runs 6–7 — SdH spot checks (`sdh-spot-check`), D = 0: electron n = +3.2×10¹², hole n = −1.2×10¹²

Raw R(B) first, then `sdh_onset` + FFT against the tetralayer model (F_L = (h/4e)·n at the run-5 calibration, **scale not yet pinned**). Run 6's grid is 50 mT below 1 T (Nyquist 2.5 T there), so its onset/FFT floor is 1.0 T; run 7 is 20 mT uniform.

**Read — electron (run 6):** strong oscillations, R from ~15 Ω (1–3 T) up to 530 Ω (quantum-Hall-like minima near 0 Ω at 6.0 and 7.2 T; a step to ~500 Ω above 7.8 T). The tones are **7.3, 14.9, 22.4, 29.4 T** (plus 37, 44, 59 T above ~2–4 T). `sdh_onset` flags 14.9 / 22.4 / 29.4 T as harmonics (2×, 3×, 4×) of 7.3 T. The 7.3 T tone is **censored** at the 1.0 T record edge: it is still alive where the fine grid starts. **The harmonic reading is not safe here.** 7.3 + 22.4 = 29.7 ≈ 29.4 T, so if 29.4 T is F_L, the pair closes the Luttinger sum at a single global scale ≈ 0.90, inside the ~0.8–1.2 lever-arm band. At scale 0.90 the ABAB model puts its pair at 6.6 / 23.2 T and ABCA at 29.8 T. The model's heavy/light ratio at this density is 3.5, while the measured one is 3.07: this is exactly the investigation's warning case ("the ABAB ratio drifts through 3× … a ratio-only screen eats the real heavy tone"). The 29.4 T tone gets stronger at high B (the dominant peak in the 3–10 T window, secondary in 1.2–3 T). That is the pattern expected of a breakdown sum-tone, but a heavier Dingle/LK envelope does the same, so it is **not yet decisive**. **One density cannot separate** {ABAB pair + breakdown sum-tone} from {7.3 T fundamental + comb, plus an F_L singleton}. The tones' **n-dependence** separates them: across n = 1.8 → 3.2×10¹² the model's heavy tone moves 15.7 → 25.9 T while 3 × light moves 8.8 → 22.2 T and F_L moves 18.6 → 33.1 T.

**Read — hole (run 7):** clean, low-onset oscillations: the dominant 6.8 T tone is still alive at the 0.5 T analysis floor (censored). The 12.3 T tone (≈ F_L) dominates above 3 T; weaker tones sit at 4.6, 8.5 and 15.8 T. But the hole side of the D = 0 line reaches only −1.27×10¹², which is the **low-|n| exception regime**: the ABAB pair there is 5.9 / 6.5 T, 0.7 T apart. Separating it needs a 1/B record ≳ 2/0.7 ≈ 2.9 T⁻¹ (onset ≲ 0.33 T), and this record's δF is ≈ 0.5 T. **Not decisive by construction.**

**Take:** both sides are alive and oscillating. The fan goes on the **electron side**, the only side whose D = 0 densities reach the separating regime (|n| ≳ 2×10¹²). Its job is to follow each tone across density.
