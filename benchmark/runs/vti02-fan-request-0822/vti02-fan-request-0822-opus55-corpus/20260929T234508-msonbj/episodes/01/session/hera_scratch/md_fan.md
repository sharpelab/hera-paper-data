## HERA — Step 4: Landau fan, electron side, D = 0 (`landau-fan-vti`, for `tetralayer-stacking-fs-count`)

**Why this side and window.** Spot checks (ana, runs 6–7): the **electron side** (run 6, n = +3.2×10¹²) carries clean tones at **7.3 T and 22.2 T, plus a 29.4 T tone right at their sum** (7.3 + 22.2 = 29.5 T). F_L = 33.1 T, so the global scale comes out ≈ 0.89 whichever way this is read: as an ABAB pair plus a breakdown sum tone, or as an ABCA singleton plus a 7.3 T partner. At one density this set can't decide. Three things can: (i) the harmonic screen by n-dependence (22.2 ≈ 3 × 7.3 at this density only; the ABAB heavy/light ratio drifts with n, a harmonic doesn't); (ii) the partition f₁ + f₂ = F_L across density; (iii) the F_L-tone origin. The **hole side** only reaches n = −1.27×10¹² (TG limit), which is the investigation's close, balanced near-CNP exception regime (run 7: 4.6 / 6.8 / 12.3 T, not decisive). So the fan goes on the electron side. **n = +3.20 → +2.00×10¹²** at D = 0. The top column is run 6's density, so the fan's top column can be checked against the spot check at the same density. The bottom is the lowest density where the claim's binding separation still clears 2·δF: with scale 0.89 and the model, the heavy tone sits ≈ 3.0 T below F_L there, against δF = 0.99 T.

**Grid (landau-fan step 1 checks).** *B_lo = 0.85 T*: `sdh_onset` on run 6's Nyquist-valid record, where the carrying 7.3 T tone and the 22.2 T tone are **censored at that edge**. Below 1 T run 6 was stepped at 50 mT, which undersamples 7 T tones below about 0.84 T. *d(1/B) = 0.0075 T⁻¹* (Nyquist 66.8 T). Nyquist on F_L alone would allow 0.0149, but run 6 shows harmonic/sum content at 44–58 T below 5 T. At 0.0149 the 2 × 29.4 T harmonic would fold onto 7.2 T and 2 × 22.2 T onto 22.8 T, i.e. exactly onto the claim tones. *B_hi = 6 T*: δF = 0.99 T, against 0.93 T for a 10 T top. Above about 5 T run 6 turns into QH-regime structure (89 / 118 T components, onset above 5 T, which this grid would alias), and the light pocket empties near 7 T. The high-field half of the F_L-tone B-window split uses run 6 (0–10 T at n = +3.2). *N_n = 31* (step 0.040×10¹²): 2 points per LL at B_lo (Δn_LL = 0.082×10¹² at scale 1, conservative). **Coverage trade:** the light partner gets ≥ 5 periods only for n ≳ 2.5–2.7×10¹², so below that it is tracked, not claim-grade. Pinning an onset below 0.85 T and extending B_lo to 0.7 T would cost about +45 % (more rows plus a tighter n step) for resolution the claim doesn't need.
