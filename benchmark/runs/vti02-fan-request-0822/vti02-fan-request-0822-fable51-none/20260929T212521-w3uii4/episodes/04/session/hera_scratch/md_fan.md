## HERA — Step 4: Landau fan at D = 0 (`landau-fan`), n fast over the full window, B 0 → 10 T

**Plan step 4** (`hera_scratch/plan.md`; operator-requested). The spot checks (runs 6, 7 — ana read landed above) show SdH from ≈ 1.0–1.4 T and, on the electron side, tones at 7.1 / 14.1 / 22.1 / 29.5 T: at the spot-check FFT resolution (~1.6 T) "harmonics of 7.1" and "light pocket 7.1 + heavy pocket 22 + total 29" are indistinguishable, and 29.5 T ≈ 0.89 × F_L(n_raw) says the run-5 density *scale* (c_tg anchored at the 9.5 nm prior) is probably ~11 % high. The fan resolves all three at once: **(i)** fan-line slopes ν = n h/(eB) fix the absolute n scale, **(ii)** the first QH gaps around the CNP (ν = ±8 for ABAB/ABCA vs ±6 + e/h asymmetry for ABCB), **(iii)** LL crossings (two cyclotron masses: ABAB/ABCB) vs a clean single-band 4-step ladder (ABCA). The series region B (CNP offset −0.43e12 raw, run 5) will draw a replica fan converging to n ≈ −0.43 — read it as such, not as crossings.

**Design.** Fast axis = (V_tg, V_bg) co-swept along the run-5 D = 0 line (direction set by the data-calibrated ratio 0.773 + D_offset; only the n *labels* carry the scale uncertainty), n_raw = −1.24 … +3.21 ×10¹² in 0.025 steps (179 pts; 3.9 pts per LL period at 1 T, 7.7 at 2 T — the sub-1 T rows are baseline only). **Coverage trade:** the hole side stops at −1.24 (TG −0.3 V limit) and D is fixed at 0; ±D is plan step 5, and the operating box is not probed. Slow axis: a B = 0 baseline row (checks against run 5's D = 0 cut: CNP ≈ 300 Ω near n = 0, region-B peak near −0.43), then 0.6 → 10.0 T at 0.2 T (48 rows) — the magnet sits at 0 (handoff readback +0.003 T), so the fan runs up and ends at the 10 T cap; step 5 rides it down. `sr1` fixed at 100 µV = 10 kΩ FS (run-5 proven; a CNP rail above 10 kΩ at high B would itself be a read). Dwell fast 1.0 s (3.3 τ, run-5 calibrated), slow 3 s; leak guard 1 nA → interrupt + park.

**Price** (from run 5: 1.07 s/pt pure + flyback, ramp 0.2 T at 0.137 T/min = 88 s + 3 s settle per row): 179 × 1.07 + 3.6 + 3 + 91 ≈ 288 s/row × 48 + the 0 T row ≈ 3 h 58 m; with the session's 5–10 % overrun → **≈ 4 h 20 m**, 8771 points. **Checkpoints** (hera-watch `--next --follow` armed): *first rows* — the B = 0 row must reproduce run 5's D = 0 cut (else the line is wrong → abort), sensitivity and TG/BG currents at the electron end; *~3 T* (row ~13, ~1 h) and *~6 T* (row ~28, ~2.3 h) — re-form the landed fan, check that fan lines are visible and converge on the CNP, fit slopes for the n scale, look for crossings; abandon if the map is featureless above 2 T (then the read is T_e-limited and a fan at this T cannot decide) or if the CNP column rails across most of the row.
