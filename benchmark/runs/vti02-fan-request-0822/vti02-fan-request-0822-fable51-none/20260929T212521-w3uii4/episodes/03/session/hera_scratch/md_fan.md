## HERA — Step 4: Landau fan along D = 0 (`landau-fan`), n −1.2 → +3.2×10¹², B 1 → 10 T

**Why now (plan step 4; operator's ask).** The spot checks say the CNP-adjacent physics is not a single band: run 6 (n = +3.2, `data/6`) has deep QH minima at 5.93 / 7.16 T with Δν = 4 spacing (F ≈ 34.5 T — implying n ≈ 3.45×10¹², i.e. the geometry-prior density scale is ~8 % low) **plus** a dominant light-mass 7.2 T tone visible from 0.5 T with harmonics to 4×; run 7 (n = −1.2, `data/7`) has F_L ≈ 12.3 T plus F_L/2 (6.8 T) and F_L/4 (3.5 T). A 1D cut cannot tell a genuine second band (ABAB / ABCB) from the region-B series copy (CNP offset −0.43×10¹², run 5) or from harmonics. The fan does: fan lines are ν = n h/(eB) straight lines through the **CNP** — a second band shares the CNP, a region-B copy emanates from a CNP shifted by 0.43×10¹²; the first gap out of the CNP (ν = 4 / 8 / 2) reads LL0's degeneracy (ABAB 8+8, ABCA 16, ABCB 4+12); the line slopes fix the absolute n scale independently of c_tg.

**Geometry.** Slow: `magnet.field` 1.0 → 10.0 T in 0.15 T steps (61 rows; below 1 T neither spot check had resolvable content). Full realized D = 0 window inside the validators — no coverage cut; hole side stops at −1.2 because the TG limit (−0.3 V) does.
